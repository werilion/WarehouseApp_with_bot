# WarehouseApp: чат-бот и техподдержка

## Что добавлено
- **Помощник** (меню «🤖 Помощник») - чат-бот по дереву решений. Понимает свободный текст по ключевым словам
  (с учётом опечаток), отвечает на частые вопросы, отвечает на вопросы про права сам по роли пользователя,
  открывает нужные разделы программы кнопкой «➡ Открыть ...» и передаёт вопрос в техподдержку.
- **Техподдержка** (меню «🛟 Техподдержка») - форма обращения (тема, описание, контакт), контакты и список обращений.
  Пользователь видит свои обращения, администратор - все и меняет их статус (Новое -> В работе -> Закрыто).
- **Database/CreateDatabase.sql** - скрипт создания базы WarehouseDB с нуля (таблицы, ограничения, индексы, тестовые данные).
- Модульные тесты бота: `WarehouseApp.Tests/UnitTests/BotEngineTests.cs`.

## Запуск
1. Выполните `Database/CreateDatabase.sql` в SQL Server Management Studio или в Visual Studio
   (SQL Server Object Explorer -> `(localdb)\MSSQLLocalDB` -> новый запрос).
   **Скрипт удаляет базу WarehouseDB, если она уже есть, и создаёт её заново.**
2. Откройте `WarehouseApp.sln` и запустите проект. Строка подключения уже указывает на `(localdb)\MSSQLLocalDB`, база `WarehouseDB`.
3. Учётные записи после создания базы:

| Логин   | Пароль     | Роль             |
|---------|------------|------------------|
| admin   | admin123   | Администратор    |
| manager | manager123 | Менеджер         |
| sklad   | sklad123   | Сотрудник склада |

Пароли в базе хранятся как SHA-256 (так же, как это делает `SecurityHelper`).

## Если база у вас уже была
Не нужно пересоздавать её целиком: достаточно добавить таблицу обращений (блок `CREATE TABLE dbo.SupportTickets`
и её индекс из скрипта) в существующую базу.

## Где что менять
| Что                                   | Где                                            |
|---------------------------------------|------------------------------------------------|
| Контакты техподдержки                 | `Services/SupportInfo.cs` (телефон, e-mail, время работы - поставьте свои) |
| Дерево диалога (вопросы, ответы)      | `Services/BotKnowledge.cs`, строка `Tree`      |
| Ключевые слова, частые вопросы        | `Services/BotKnowledge.cs`: `Intents`, `Faqs`, `SmallTalk` |
| Логика диалога (роли, переходы, поиск) | `Services/BotEngine.cs`                        |
| Окно чата и форма обращения           | `Views/ChatView.xaml`, `Views/SupportView.xaml` |

## Как работает бот
1. Сообщение приводится к нижнему регистру, знаки препинания убираются.
2. Если пользователь отвечает словом на текущий вопрос («да», «нет», название ветки), бот идёт по дереву.
3. Иначе ищет по ключевым словам: сначала частые вопросы, затем темы, ведущие в нужное место дерева.
4. На вопросы о правах («Вы администратор?») бот отвечает сам по роли из `Session.CurrentUser`.
5. Если ничего не найдено, предлагает выбрать тему кнопкой.

Нейросеть не используется.
